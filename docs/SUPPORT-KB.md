## Install: iPhone
- Requirements: eSIM-compatible iPhone (XS and later), unlocked, iOS updated, Wi-Fi connection.
- Steps: Settings → Cellular → Add eSIM → scan QR. Label it "Travel". Keep it OFF until landing.

## Install: Android
- Varies by maker (Samsung/Pixel/Xiaomi flows differ) — per-brand steps to be written.

## At destination (activation)
- Turn eSIM line ON, enable Data Roaming **on the eSIM line only**, primary SIM data OFF.
- Not working: toggle airplane mode, restart, verify APN (per provider), check plan start time.

## Common issues
- "Scanned but no service" / "QR won't scan" (manual entry codes) / "Used my data too fast" / "Phone is carrier-locked" — full answers TBD.

## Policies
- Refunds: unactivated + <30 days + ≤$30 → automatic. Above → tier-2 human.
- No refunds after activation except provisioning fault.

## Escalation triggers (bot logic)
- Refund > threshold; anger/frustration signals; 2 failed resolution attempts; anything legal/payment-dispute.
